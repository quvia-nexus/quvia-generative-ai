PART 1

AI 핵심 개념 사전 🔑

AI를 이해하는 데 꼭 필요한 8가지 핵심 단어를 배워요!

📝 프롬프트 (Prompt)
💭핵심 개념

프롬프트란?

AI에게 내리는 명령어 또는 질문입니다. 사람이 AI에게 말을 걸 때 쓰는 언어예요. 좋은 프롬프트일수록 AI가 더 좋은 답을 줘요!

예시: "초등학생에게 태양계를 설명해줘" → 이것이 바로 프롬프트!
🛠️ 프롬프트 엔지니어링

AI에게 원하는 답을 얻기 위해 프롬프트를 설계·최적화하는 기술입니다.

1
역할 부여AI에게 "너는 친절한 선생님이야"처럼 역할을 줘요
2
맥락 설명상황을 자세히 알려줄수록 더 정확한 답이 나와요
3
형식 지정"표로 만들어줘", "3줄로 요약해줘" 처럼 결과 형태를 지정해요
4
예시 제공원하는 답변의 예시를 보여주면 더 잘 이해해요
🗣️ 자연어 처리 (NLP)
🌀 환각현상 (Hallucination)
⚠️ 주의! AI가 사실이 아닌 내용을 마치 사실인 것처럼 자신감 있게 말하는 현상이에요.
예: "세종대왕이 1800년에 한글을 만들었다" — 완전히 틀린 정보인데도 자신 있게 말할 수 있어요!
❓
왜 생길까?AI는 확률로 단어를 예측해요. 정확한 정보가 아닌 "그럴듯한" 단어를 고르다 보니 틀릴 수 있어요
✅
대처법AI의 답변을 항상 교과서나 믿을 수 있는 사이트로 다시 확인하세요!
🤖 머신러닝 (Machine Learning)

컴퓨터가 데이터를 보고 스스로 규칙을 학습하는 기술이에요. 사람이 일일이 가르쳐주지 않아도 돼요!

🕸️ 딥러닝 (Deep Learning)

사람의 뇌 구조를 흉내 낸 신경망(Neural Network)을 여러 층으로 쌓아 만든 기술이에요.

🎯 파인튜닝 (Fine-tuning)
비유로 이해하기 🎸
큰 AI 모델 = 기본기가 있는 뮤지션
파인튜닝 = 특정 장르(재즈, 클래식)에 맞게 추가 훈련!
→ 의료용 AI, 법률 AI 등을 만들 때 사용해요
단계설명
① 기반 모델 선택ChatGPT, Claude 등 큰 AI 선택
② 특화 데이터 준비의료 논문, 법률 문서 등 전문 데이터
③ 추가 학습소량 데이터로 빠르게 재훈련
④ 전문 AI 완성의사 도움 AI, 법률 상담 AI 등 탄생!
🔢 토큰 (Token)

AI가 언어를 처리하는 최소 단위예요. 단어, 음절, 기호 하나하나가 토큰이 될 수 있어요.

PART 2

생성형 AI 원리 심화 🧠

LLM과 확산 모델의 원리를 깊이 이해해요!

📖 LLM — 거대 언어 모델

Large Language Model: 엄청난 양의 텍스트 데이터로 학습된 AI 모델이에요. ChatGPT, Claude, Gemini 모두 LLM이에요!

🔍어텐션

어텐션 메커니즘

문장에서 중요한 단어에 집중하는 기능이에요. "나는 사과를 먹었다. 그것은 맛있었다"에서 '그것'이 '사과'를 가리킨다는 걸 이해해요.

⚙️파라미터

파라미터

AI 모델이 학습을 통해 얻은 수많은 숫자값이에요. GPT-4는 약 1조 개! 숫자가 클수록 더 똑똑해요.

🎨 확산 모델 (Diffusion Model)

이미지 AI(Midjourney, DALL-E, Stable Diffusion)의 핵심 기술! 노이즈에서 이미지를 만들어 내요.

🎯 핵심 포인트!
확산 모델은 역방향으로도 학습해요:
깨끗한 이미지 → 노이즈 추가 (순방향 학습) →
노이즈 → 이미지 복원 (역방향 = 실제 사용)
PART 3

프롬프트 실전 💬

4요소 전략과 이터레이션으로 AI를 내 마음대로 활용해요!

🎯 프롬프트 4요소 전략
👤요소 1

역할 (Role)

AI에게 어떤 역할을 맡길지 설정해요
"너는 친절한 과학 선생님이야"

📋요소 2

맥락 (Context)

상황과 배경을 자세히 설명해요
"초등학교 5학년이 이해할 수 있게"

✏️요소 3

지시 (Instruction)

구체적인 할 일을 명확하게 써요
"태양계 8행성을 표로 정리해줘"

📐요소 4

형식 (Format)

원하는 결과 형태를 지정해요
"글머리 기호로, 200자 이내로"

💡 4요소 조합 예시:
"너는 [역할: 친절한 과학 선생님]이야. [맥락: 초등 5학년 학생에게] [지시: 태양계 행성을 설명]해줘. [형식: 각 행성마다 3줄씩, 재미있는 비유 포함]"
🔄 이터레이션 (Iteration)

프롬프트를 반복해서 수정·개선하는 과정이에요. 한 번에 완벽한 답이 나오지 않아도 괜찮아요!

1
첫 프롬프트 시도"지구온난화에 대해 설명해줘"
2
결과 확인 & 개선"너무 어려워. 초등학생 눈높이로 다시 써줘"
3
더 구체적으로 요청"실생활 예시 3가지 포함해서 짧게 써줘"
4
완성! 🎉원하는 결과물 완성! 저장해두기

바이브 코딩 & AI 윤리 ⚙️

AI와 함께 코딩하고, 올바른 AI 사용법도 배워요!

💻 바이브 코딩이란?
바이브 코딩 (Vibe Coding): AI에게 "어떤 프로그램을 만들고 싶다"고 말하면 AI가 코드를 써주는 새로운 코딩 방식이에요!

"수학 문제를 내고 점수를 매기는 퀴즈 게임 만들어줘" → AI가 Python 코드 완성!
🤖AI 코딩 도구

GitHub Copilot

코드 작성 중 다음 줄을 자동 완성해 주는 AI 도구. 전문 개발자도 많이 사용해요!

⚡AI 코딩 도구

Cursor / Replit

대화하면서 코딩하는 AI 통합 개발 환경. 초보자도 쉽게 앱을 만들 수 있어요!
